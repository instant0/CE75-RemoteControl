# Writing (docs, rules, replies)

## DO
- DO / DON'T lists, short tables, fixed paths/commands
- Put facts once; point to the file
- **If you learn something → document it before anything else** (no next scan/edit until the fact is in the right file)

## DON'T
- War-and-Peace history, battle stories, “why we suffered”
- Multi-page essays for a one-line rule
- Duplicate the same rule in five files
- Hold new facts only in chat / session memory
