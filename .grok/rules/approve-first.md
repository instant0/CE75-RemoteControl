# Approve-first (every task)

**Tattoo:** No dig, edit, scan, or multi-step work until the user approves a ≤10-word plan.

## DO
- Before any work: state the plan in **10 words or less**
- Wait for explicit approval (yes / go / do it / equivalent)
- One plan = one step; re-approve if the approach changes mid-task
- STOP / no → halt immediately; no “one more probe”

## DON'T
- Start tools, relay, CT/CEA edits, or bulk docs before approval
- Race ahead after partial results without a new ≤10-word plan
- Ignore anchors you already have in favor of global scans
- Treat “look into X” as blanket approval for thrash digs
